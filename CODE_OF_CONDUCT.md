# Code of conduct

Be decent to the people who report bugs, review changes and ask questions.

- Critique the work, not the person
- No harassment, slurs or unwanted sexual attention
- Don’t post other people’s private data, keys or clipboard contents

The SAVISUL Authors maintain this project and will warn, then block, anyone who ignores this.

Report a problem to [mouldloft@gmail.com](mailto:mouldloft@gmail.com).
